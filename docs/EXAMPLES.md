## How we got these results

Nothing here is hand-picked or retyped: the tables come straight from the run results. Links to public sources go to the web; the others are files in this lab (gitignored, so there is no public repository).

### The pipeline behind C and D

- **1. Real names**: Every team and player is looked up on Wikidata, which stores how each language’s editors spell them (lt “Kauno Žalgiris”, lv Kauņas “Žalgiris”). [bbl/entities.py](../bbl/entities.py)
- **2. Every grammatical form**: A table of every case form per name is built once per match: drafted by Claude, overwritten by the Tēzaurs morphology service for Latvian players, then corrected with forms checked against native sports press. [bbl/inflect.py](../bbl/inflect.py) · [bbl/tezaurs.py](../bbl/tezaurs.py) · [bbl/press.py](../bbl/press.py)
- **3. Local knowledge in the prompt**: A style sheet, a sport glossary and example buffs per language go into one prompt, with the match facts. [bbl/locale_pack.py](../bbl/locale_pack.py)
- **4. Written, not translated**: Claude writes the buff directly in the fan’s language and adds an English meaning for the operator. Output must match a fixed schema. [bbl/generate.py](../bbl/generate.py) · [bbl/schemas.py](../bbl/schemas.py)
- **5. Automatic checks**: Spelling (Hunspell), missing accents, letters from the wrong Baltic alphabet, banned literal translations, plural-only nouns, register and card length, in milliseconds. [bbl/validators.py](../bbl/validators.py) · [bbl/spell.py](../bbl/spell.py)
- **6. Five specialist reviewers (D only)**: Grammar, sport terms, names, native ear and facts check the buff in parallel. A plain-code orchestrator drops false alarms and sends real problems back for at most two repairs. [bbl/reviewers.py](../bbl/reviewers.py) · [bbl/pipeline.py](../bbl/pipeline.py)

### Models

- **claude-opus-5-5**: Writes the buffs for all four columns here, builds the case tables, runs four of the five reviewers (and the fifth when Gemini is overloaded) and is the main judge. [Claude models](https://docs.claude.com/en/docs/about-claude/models/overview)
- **Gemini 3.6 Flash, falling back to 3.5 Flash-Lite**: The second, cross-vendor judge and the native-ear reviewer. Overloaded often, so it falls back to Claude. [Gemini models](https://ai.google.dev/gemini-api/docs/models)
- **claude-sonnet-5-5**: The model JIL’s backend uses today; used in an earlier run to show today’s results on today’s model. [Claude models](https://docs.claude.com/en/docs/about-claude/models/overview)

### How the cards were scored

- Same 18 moments, same model for all four columns, so differences come from the method. [bbl/judge.py](../bbl/judge.py)
- The judge is blind: it sees the match facts and the card, never the English source or which column wrote it.
- It lists errors MQM-style, the method WMT uses (GEMBA-MQM), with severities, and scores grammar, naturalness, terminology, facts and engagement from 1 to 5. Approved means no major or critical errors. [GEMBA-MQM paper](https://arxiv.org/abs/2310.13988) · [WMT25](https://machinetranslate.org/wmt25)
- A second judge from another vendor (Gemini) scores the same cards to check for same-family bias. It scored most B, C and D cards; column A comes from an earlier run that did not use it.
- Judges get the press evidence, so a correctly spelled name isn’t marked wrong. Column A was scored before this was added, which is why one A card shows a false flag on “Donnarumma”.
- Raw results: every buff, issue, judgement, repair round and team decision. [run A](../out/run-20261117-232937/results.json) · [run B, C, D](../out/run-20261117-235224/results.json)

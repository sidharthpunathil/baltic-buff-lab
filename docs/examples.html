The pipeline behind columns C and D

1. Real names

Every team and player is looked up on Wikidata, which stores how each language’s editors spell them (lt “Kauno Žalgiris”, lv Kauņas “Žalgiris”).

2. Every grammatical form

3. Local knowledge in the prompt

A style sheet, a sport glossary and example buffs per language go into one prompt, with the match facts.

bbl/locale_pack.py
4. Written, not translated

Claude writes the buff directly in the fan’s language and adds an English meaning for the operator. Output must match a fixed schema.

5. Automatic checks

Spelling (Hunspell), missing accents, letters from the wrong Baltic alphabet, banned literal translations, plural-only nouns, register and card length, in milliseconds.

6. Five specialist reviewers (D only)

Grammar, sport terms, names, native ear and facts check the buff in parallel. A plain-code orchestrator drops false alarms and sends real problems back for at most two repairs.

How the cards were scored

  • Same 18 moments, same model for all four columns, so differences come from the method.bbl/judge.py
  • The judge is blind: it sees the match facts and the card, never the English source or which column wrote it.
  • It lists errors MQM-style, the method WMT uses (GEMBA-MQM), with severities, and scores grammar, naturalness, terminology, facts and engagement from 1 to 5. Approved means no major or critical errors.GEMBA-MQM paper ↗ WMT25 ↗
  • A second judge from another vendor (Gemini) scores the same cards to check for same-family bias. It scored most B, C and D cards; column A comes from an earlier run that did not use it.
  • Judges get the press evidence, so a correctly spelled name isn’t marked wrong. Column A was scored before this was added, which is why one A card shows a false flag on “Donnarumma”.
  • Raw results: every buff, issue, judgement, repair round and team decision.run A run B, C, D

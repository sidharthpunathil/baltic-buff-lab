# Baltic Buff Lab

Research and a working proof of concept for writing JoinInLive buffs that Lithuanian, Latvian and Estonian fans read as their own. It started inside the JoinInLive codebase and now lives in its own repository.

**Outcome so far:** on the same model (`claude-opus-5-5`), today's native prompt produced 21 major errors across 18 buffs. The new pipeline produced 1. A judge from a second vendor approved 15 of 17 of its buffs, against 6 of 11 for today's prompt.

## What changed for fans: three examples

All three come from the same runs and the same model. "Major" errors are what a blind native-language judge flagged; the English line is each buff's own English meaning.

**Latvian, football. 67th minute, Estonia trail Italy 0:1, VAR awards Estonia a penalty.**

| Approach | Buff | Judge |
|---|---|---|
| Today: Translate button | VAR piešķir Igaunijai **pendeli** pie 0-1. Vārtos Donnarumma. Kas notiks? | 3 major: "pendele" is slang that the press only prints in quotes; Donnarumma flagged too\* |
| Today: native prompt | 67. minūtē pēc VAR pārbaudes Igaunijai **soda sitiens**. Kā tas beigsies pret Donnarummu? | 3 major: bare "soda sitiens" can mean a free kick |
| New pipeline | Vai Igaunija realizēs **11 metru soda sitienu** pret Donnarummu? | approved, no errors |

English: "Will Estonia convert the 11-metre penalty kick against Donnarumma?"

\* That Donnarumma flag was a judge mistake. Latvian press does print "Donnarumma", and the pipeline now gives every judge that evidence.

**Estonian, ice hockey. Canada takes a tripping minor; Latvia goes on the power play.**

| Approach | Buff | Judge |
|---|---|---|
| Today: Translate button | Kas Läti **lööb** ülekaalus värava? | 3 major: "lööb" is the football verb |
| Today: native prompt | Kas Läti **lööb** seisul 1:1 ülekaalus värava? | 2 major: football verb, unfinished option |
| New pipeline | Seis on 1:1. Kas Läti **viskab arvulises ülekaalus** värava? | approved, no errors |

English: "It's 1:1. Will Latvia score on the power play?" Estonian broadcasters say a hockey goal is "thrown" (viskab), not "kicked".

**Lithuanian, ice hockey. Latvia's goalkeeper Elvis Merzļikins has made 31 saves.**

| Approach | Buff | Judge |
|---|---|---|
| Today: Translate button | **Merzļikins** po dviejų kėlinių atrėmė 31 metimą. Kaip **vertinate** jo žaidimą? | 2 major: name not in Lithuanian form, formal "you" |
| Native-first pipeline (round 1) | **Merzlikinas** atrėmė jau 31 metimą. Ar jis – geriausias rungtynių žaidėjas? | 3 major: name lost its ļ |
| New pipeline (round 2) | **Merzļikinas** atrėmė jau 31 metimą. Ar jis – geriausias šių rungtynių žaidėjas? | approved, no errors |

English: "Merzļikinas has already saved 31 shots. Is he the best player of this match?" Lithuanian press (sportas.lt) keeps the Latvian ļ and adds the Lithuanian ending. The round-2 pipeline checks name forms against the press; round 1 didn't.

The old methods don't fail every time: for 4 of the 18 moments both were approved. The full gallery shows all 18, good and bad.

## Live app

`app/` is a React app on top of the real pipeline. Pick a match moment and a language, and today's methods race the new pipeline side by side. Every model call streams in as it happens, and you can open any step to see the exact system prompt and user message it received, what it returned, the tokens and the cost. A second view opens each of the six pipeline stages onto its real data: Wikidata labels, case tables before and after the press check, the style sheet and glossary, the assembled prompt colour-coded by section, a validator playground and the five reviewers. See [`app/README.md`](app/README.md).

```bash

```

## Results

18 buffs per approach (3 simulated matches × 2 live moments × 3 languages), all generated by `claude-opus-5-5`, scored by an independent panel.

|---|---|---|
| A. Today's Translate button | 5/18 | 30 |

A live buff takes a median of 13.5 seconds and about 4 cents with all-Claude review and a warm prompt cache (`tools/timing.py`).

Per-language results, run-to-run variance, latency and the public benchmarks behind the model choices are in [`BENCHMARKS.md`](BENCHMARKS.md). The raw results for every number are in [`benchmarks/`](benchmarks/).

## How it works, briefly

1. **Before kickoff**, every team and player gets a table of all their grammatical forms, built from Wikidata labels, the Tēzaurs morphology service for Latvian, and forms checked against native sports press.
2. **The model writes in the fan's language** from the match facts, with a style sheet, a sport glossary, the name tables and example buffs. It also returns an English meaning for the operator.
3. **Deterministic checks** catch spelling, missing accents, literal translations and broken rules in milliseconds.
4. **Five specialist reviewers** (grammar, sport terms, names, native ear, facts) check the buff in parallel. Plain-code orchestration drops false alarms, blocks only real problems and routes fixes back for up to two repairs.
5. **The operator** gets the buff, its English meaning and any open flags.

The full explanation, including data formats, every validator rule, the orchestrator logic and how to extend each part, is in [`docs/HOW-IT-WORKS.md`](docs/HOW-IT-WORKS.md).

## Run it

```bash
cd baltic-buff-lab
uv sync
cp .env.example .env                    # add ANTHROPIC_API_KEY (GEMINI_API_KEY optional)
uv run pytest -q                        # 22 offline tests
uv run python -m bbl.cli run samples/events/*.json --langs lt,lv,et --arms A,B,C,D
python3 -I tools/build_examples.py      # rebuild the examples gallery
```

Method B reads JIL's `sports_native` prompt from `../backend/app/prompts/packs/sports_native/feed_buff_gen/system_prompt.txt`, which isn't in this repository. Without that file, run methods A, C and D. The name tables for the sample matches are committed in `data/cache/`, so runs don't need to rebuild them.

## What to try next

- **TildeOpen-30b as a grammar ranker.** It is open-weight and built for these languages. On the MultiBLiMP grammar test it scores 99.7% (lt), 99.1% (lv) and 98.3% (et), against 95.3%, 91.6% and 92.0% for Gemma 2 27b. It is a base model, so it should pick the best of several drafts rather than write them.
- **Best model per language.** On the Estonian EKI leaderboard Claude Fable 5.2 ranks first and Opus 5.5 fourteenth.
- **Native-written templates** for the most common moments (next goal, who wins the half).
- **Vabamorf** for rule-based Estonian name forms, as Tēzaurs does for Latvian.
- **Learning from operator edits** once JIL captures them.

## Limits

- The Claude judge reads the same style sheet as the new pipeline, which can favour it. The second-vendor judge offsets this partly; native raters are the real test.
- The example buffs and several style rules are research drafts that no native speaker has reviewed.
- 18 buffs per approach is enough to see the direction, not a benchmark.
- Gemini Flash was often overloaded (one review took 200 seconds), so it should stay off the live path.

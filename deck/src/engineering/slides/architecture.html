POC: baltic-buff-lab/bbl

Linguists fix language problems without an engineer: all language data lives in plain files

REFERENCE DATA

entities.py Wikidata labels, disk cache
inflect.py LLM case tables
tezaurs.py Latvian morphology API
press.py press-verified overrides

GENERATION

locale_pack.py style, glossary, examples
generate.py arms A, B, C/D prompts
llm.py structured output, model chains, usage

CHECKS

validators.py deterministic rules
spell.py Hunspell lt/lv/et
reviewers.py 5 specialists + orchestrator
judge.py MQM evaluation panel

ORCHESTRATION

pipeline.py runs arms in a thread pool, keeps a full trace; cli.py, report.py, analyze.py for runs and HTML reports.

DATA FILES

locales/<lang>/ style.md, locale.json, fewshot.json · data/glossary/ · data/names/press.json

Python 3.12, uv. Dependencies: anthropic, pydantic, google-genai, spylls, phunspell, rich, pytest. About 1,700 lines of Python across 17 modules, including config, schemas and the CLI.

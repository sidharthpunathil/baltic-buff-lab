QUALITY GATES · mapped to the repo’s CLAUDE.md rules

What each PR must prove before merge

100% COVERAGE, NO MOCKS

Validators run against real Hunspell dictionaries and real glossary files. Only the LLM and Wikidata HTTP boundary is stubbed, which the rules allow.

EDGE CASES

Empty options, quiz without an answer, NFC vs NFD text, avoid-term inside the preferred term, foreign letters inside names, hallucinated review spans.

DATA LOSS (RULE 8)

Edit capture: assert the Postgres row exists after the drain, the drain task is in the beat schedule, and a re-delivered message doesn’t double-write.

QUALITY REGRESSION

Nightly golden-set eval (150 buffs per language once natives provide them). A PR that drops approval or raises MQM penalty is flagged, not auto-blocked.
